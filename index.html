Incident reports

Production problems I've actually fixed

Formatted the way I write them at work — symptom, root cause, fix, result. Click one open.

INC-01 Monthly AWS spend trending over budget MEDIUM
SYMPTOM
EKS, Lambda, S3, RDS, MongoDB and ElastiCache costs climbing across environments with no single owner reviewing utilization.
ROOT CAUSE
Over-provisioned compute and storage tiers, no lifecycle policies, resources sized for peak rather than actual load.
RESOLUTION
Rightsized EKS node groups and Lambda memory, tuned S3 lifecycle rules, and re-provisioned RDS/MongoDB/Redis via Terraform to match real usage.
30% reduction in monthly cloud spend — $600+ saved per month
INC-02 Slow detection and diagnosis of production anomalies HIGH
SYMPTOM
Alerts across 20+ microservices required manual log triage before anyone understood what was actually failing.
ROOT CAUSE
No AI-assisted root-cause analysis and fragmented visibility between application, infra and cache metrics.
RESOLUTION
Rolled out Dynatrace AIOps for anomaly detection, and built Grafana dashboards on Prometheus + CloudWatch covering every service.
Mean time to resolution improved by 35%
INC-03 Rising API latency under load, database near saturation HIGH
SYMPTOM
API response times climbing during peak traffic, database connections pushed close to their limit.
ROOT CAUSE
Every request hit the primary database directly — no caching layer for session or frequently-read data.
RESOLUTION
Introduced Redis ElastiCache for session management and hot-path caching in front of the database.
DB load down 40%, API response time down 50%
INC-04 Configuration drift between environments, slow deploys MEDIUM
SYMPTOM
Staging and production infra quietly diverged over time; deployments took longer than they should have.
ROOT CAUSE
Infrastructure changes were made manually, with no single source of truth for environment state.
RESOLUTION
Migrated all provisioning to Terraform, making every environment reproducible from code.
Deployment time down 60%, drift eliminated
INC-05 Platform not ready for enterprise compliance review HIGH
SYMPTOM
Enterprise prospects asked for ISO/SOC 2 evidence the platform couldn't yet provide.
ROOT CAUSE
No segregated QA/production environments, no governed deployment approvals, no audit trail.
RESOLUTION
Led the ISO and SOC 2 implementation — environment segregation, governed release controls and audit logging built into the pipeline.
Certification-ready infrastructure shipped
